# Wang Builds Homebrew Tap

Official Homebrew tap for [@wang-builds](https://github.com/wang-builds) native macOS open-source tools.

## Install CutWord (剪字)

```bash
brew install --cask wang-builds/tap/cutword
```

Installs both **`CutWord.app`** in `/Applications` and the **`cutword`** CLI in `/opt/homebrew/bin/cutword`.
